=== FOX.SKLEP.PL ===
Własny motyw dla FOX.SKLEP.PL (WordPress + WooCommerce).

Motyw nie zmienia adresów URL, tytułów SEO, opisów ani danych strukturalnych –
wyświetla istniejące treści w nowym układzie.

Ustawienia: Wygląd → Dostosuj → FOX.SKLEP.PL
Menu: Wygląd → Menu (lokalizacje: Menu główne, Stopka – kolumny 1–4)
Filtry kategorii: Wygląd → Widżety → Filtry sklepu
Komplet: edycja produktu → Produkty podlinkowane → Zbuduj komplet – części
Opis pod produktami: edycja kategorii produktu → Opis pod produktami (motyw FOX)
